## 1. Platform & Multi-Tenant Architecture

* **Stack:** NestJS (`apps/api`), React + Vite + TanStack Query (`apps/web`), PostgreSQL 16 with **Row-Level Security (`FORCE ROW LEVEL SECURITY`)** (`db/migrations/`), Caddy reverse proxy.
* **Tenant Isolation:** Every tenant-scoped table enforces `org_id = app.current_org_id() OR app.is_platform_superadmin()` via `DbService.withContext(ctx, ...)` executing inside a PostgreSQL transaction.
* **Feature Management (`TenantFeatures`):**
  * `feature_core_hr`, `feature_performance`, `feature_kpis`, `feature_peer_reviews`, `feature_competencies_pip`, `feature_leave_management`, `feature_time_attendance`, `feature_ph_payroll`, `feature_bank_disbursement`, `feature_bir_statutory_gen`.
  * Topbar (`Goal period` selector), Home redirect, Left Sidebar (`Sidebar.tsx`), Team/Directory goal links, and the **Help Drawer** (`HelpDrawer.tsx` + `help/content/*.md`) all respect tenant feature flags.

## 2. Implemented Modules & Recent Additions

### A. Maker-Checker Payroll & Philippine Statutory Engine (`/payroll`, `/my-payslips`)
* **Strict Maker-Checker (`0058`, `PayrollService`):**
  * `computePayrollRun`: Requires `hr_admin`, `hr_partner`, or `manager` role; records `computed_by`.
  * `approvePayrollRun`: Requires `hr_admin` or `manager` role; enforces `hr_settings.enforce_payroll_maker_checker` (default `TRUE`), blocking the preparer (`computed_by === ctx.employeeId`) from approving their own payroll run (`403 Forbidden`).
  * `disbursePayrollRun`: Requires `hr_admin` or `manager` role and `status === 'approved'`; records `disbursed_by` and `disbursed_at`, and settles active loan amortizations.
* **Statutory & Tax Filings:**
  * CSV Exports: **SSS R-3 / WISP**, **PhilHealth EPRS RF-1**, **Pag-IBIG MCRF**, **BIR 1601-C**, and Bank Disbursement batch files (**BPI, BDO, Metrobank, UnionBank**).
  * **BIR Form 2316 (`GET /api/payroll/my-bir-2316`, `GET /api/payroll/bir-2316/:employeeId`):** Annual Certificate of Compensation Payment / Tax Withheld with ₱90,000 13th-month exemption cap, De Minimis, and EE statutory deductions, printable directly from **My Payslips**.
  * **BIR Form 1601-C Summary (`GET /api/payroll/bir-1601c`):** Monthly consolidated remittance totals.

### B. Offboarding Clearance & Final Pay Engine (`/offboarding`)
* **Database (`0058`):** `offboarding_case` and `offboarding_clearance_item` tables with tenant RLS.
* **Backend (`OffboardingController` / `EssService`):**
  * Initiates separation workflows with a default 4-area clearance checklist (*IT & Assets*, *Department Handover*, *Finance & Loans*, *HR Exit Interview*).
  * `POST /api/offboarding/:id/compute-final-pay`: Auto-computes **pro-rated 13th-month accrual** (`thirteenth_month_accrual`), **unused SIL monetization** (`leave_allocation` × `daily_rate`), and **outstanding active loans** (`employee_loan`), combined with unpaid basic salary / separation pay / deductions.
  * `POST /api/offboarding/:id/release`: Enforces 100% cleared/waived checklist before releasing final pay and marking active loans `fully_paid`.

### C. Employee Self-Service (ESS), COE & Company Bulletins (`/ess`)
* **Database (`0058`):** `company_announcement` and `ess_profile_request` tables with tenant RLS.
* **Backend (`EssController` / `EssService`):**
  * **Company Announcements:** Pinned HR memos, policy updates, and holiday advisories (`GET/POST/DELETE /api/ess/announcements`).
  * **Profile & Data Change Requests:** Employees view their 201 profile, statutory IDs, and bank account, and submit update requests (`bank_account`, `government_id`, `contact_info`); HR approves/rejects in-app, automatically updating `employee_compensation` / `employee`.
  * **Certificate of Employment (`GET /api/ess/coe`):** One-click printable official COE with toggle for including monthly compensation rate.

### D. Executive Outflow & Core HR Views
* **Executive Outflow Dashboard (`/executive-dashboard`, `GET /api/reports/executive-dashboard`):** Statutory agency outflow (SSS, PhilHealth, Pag-IBIG, BIR), voluntary benefits, branch payroll spend, salary brackets, active loans portfolio, and span of control.
* **Employee Directory (`/employees`):** Searchable, filterable roster (Department, Branch, Status) with table/card views and 201 Vault links.
* **My Team (`/team`):** Direct reports roster + (when performance is enabled) Goal Approvals & Risk queue.

## 5. Build & Deployment Checklist

> **Constraint:** Always build Docker images locally (`--platform linux/amd64`) and `scp` the tar archive to EC2 (`t3.micro` cannot compile TypeScript/Vite in-place).

```powershell
# 1. Run tests & verify builds locally
pnpm --filter @hr/api build
pnpm --filter @hr/web test
pnpm --filter @hr/web build

# 2. Build & export Docker images
docker build --platform linux/amd64 -t hr-system-api:latest -f apps/api/Dockerfile .
docker build --platform linux/amd64 -t hr-system-web:latest -f apps/web/Dockerfile --build-arg "VITE_API_BASE_URL=https://hr.summitlogicsolutions.com/api" .
docker save -o hr-saas-images.tar hr-system-api:latest hr-system-web:latest

# 3. Apply new SQL migrations on EC2 Postgres & restart containers
scp -i C:\Users\Windows\.ssh\hr-system-demo.pem db/migrations/0058_enterprise_ess_final_pay_maker_checker.sql ubuntu@54.79.210.29:/home/ubuntu/
scp -i C:\Users\Windows\.ssh\hr-system-demo.pem hr-saas-images.tar ubuntu@54.79.210.29:/home/ubuntu/
```
